# Website Tester for Windows

A simple background website QA runner for Windows.

## Current scope

- Configure a homepage URL.
- Run manually or on a daily schedule.
- Open the homepage and save a screenshot.
- Discover homepage links and banner-like clickable elements.
- Visit each discovered destination.
- Verify the destination responds successfully.
- Check that the destination is plausibly related to the link/banner using its URL, title, and visible text.
- Produce a local HTML/JSON report.

Notifications and the installer are planned next.
